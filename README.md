# Japan Hidden Spots

A web app to share and review hidden tourist spots, family-owned restaurants and food stalls in Japan.

> 🚧 In development. Target v1: December 2026.

## Features (v1)
- Sign up / log in
- Add spots with prefecture, category and description
- Browse, filter by prefecture/category, search by name
- Reviews and 1–5 star ratings
- Manage your own spots and reviews

## Tech stack
React + Vite + TypeScript · Tailwind + shadcn/ui · Node.js + Express · PostgreSQL · Vitest + Supertest · GitHub Actions
